# LanCoClip

**局域网剪贴板历史工具**：后台常驻，自动留存电脑复制的文本与截图，局域网内随时查看、一键取回剪贴板，其他设备也能反向推送到电脑。

</div>

## 功能特性

### 自动记录，无需手动保存

- 电脑上每一次复制都会自动记录：**文本**和**截图 / 图片**都能存，一条不漏，程序异常退出也不会丢失刚复制的内容。
- 文本与图片**分开存储、分开查看**，互不干扰。
- **自动去重**：同一内容反复复制只保留一条，不堆积。
- 记录数量可设置上限（文本 10–5000 条、图片 5–1000 条，默认 500 / 200），超出自动清理最旧的记录。
- 从页面上复制的内容不会重复入库，避免「自产自销」的冗余记录。

### 局域网随时查看与取回

- 手机 / 平板连同一 Wi-Fi，浏览器打开页面即可看到电脑的剪贴板历史。
- 文本一键**复制**回剪贴板；图片一键**复制**或**保存 PNG 原图**。
- PC 分页浏览（每页 32 条）；手机端上滑加载更多。
- 新复制的内容实时出现；断连会提示并自动重试。

### 其他电脑/手机反向推送

- 其他电脑/手机上也能把内容推给电脑：**发文本**、**传图片**（相册 / 文件管理器选图，自动转 PNG 入库）。
- 悬浮推送按钮可**拖动**到任意位置，位置自动记住。

### 扫码即连

- 页面顶部显示局域网访问地址，一键生成**二维码**，手机扫码即开；也可一键复制访问链接。

### 桌面快捷操作（macOS / Windows）

- **菜单栏 / 托盘菜单**：打开页面、设置、暂停 / 恢复记录、最近历史、清除历史、退出。
- **手机打不开？**：Windows 托盘菜单里的排障入口。第一次监听时 Windows 防火墙会问一次是否放行，误点「取消」或当前 Wi-Fi 处于「公用网络」时，手机会一直转圈；这一项会说明怎么勾选「专用网络」并一键打开防火墙设置页。
- **最近历史**：最近 30 条一键取回，点击即复制回剪贴板。
- **全局快捷键**（可自定义，默认组合如下，可在设置中修改）：

  | 作用 | macOS 默认 | Windows 默认 |
  | --- | --- | --- |
  | 打开页面并弹二维码 | `⌘ ⇧ Q` | `Ctrl + Shift + Q` |
  | 弹出最近 30 条历史菜单 | `⌘ ⇧ V` | `Ctrl + Shift + V` |

- **开机自启**：登录后自动在后台运行，启动即弹通知，点击横幅直接打开页面；重复启动不会开第二个实例。

### 个性化设置

- **主题**：默认跟随系统，也可手动切换亮 / 暗色并记住。
- **暂停记录**：一键停止保存任何新的剪贴板内容（复制密码、验证码前可用）。托盘菜单与设置弹窗都能切换，状态写入 `settings.json`，重启后仍保持；暂停期间页面顶部会显示状态横幅。
- **保留条数**：分别设置文本、图片的记录上限，保存立即生效。
- **快捷键**：点按捕获自定义组合键，冲突时自动拒绝保存。

### 支持平台

- **macOS / Windows**：完整支持（托盘、通知、开机自启、全局快捷键、图片记录）。

## 快速开始

```bash
go build -o lanoclip .
./lanoclip                   # 默认端口 6116
./lanoclip -port 8080        # 自定义端口
./lanoclip -data /tmp/lcp    # 自定义数据目录
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-port` | `6116` | HTTP 端口；被占用时自动顺延（最多试 10 个） |
| `-tray` | `false` | 菜单栏模式；macOS `.app` 内自动开启 |
| `-data` | 用户配置目录 | 数据目录；也可用环境变量 `LANOCLIP_DIR`（优先级低于 `-data`） |

启动后终端会打印手机可访问的地址（如 `http://192.168.x.x:6116`），扫码或输入即可查看；在本机打开同一地址可以清空和修改设置（手机端不可）。

地址每秒级自动跟随网络变化：切 Wi-Fi、插网线、开 VPN 后重新打开页面或二维码即为新地址，不需要重启。选地址时优先「物理网卡的私网 IPv4」（en0 / Wi-Fi / 以太网），会自动跳过 Hyper-V、VMware、VirtualBox、Tailscale、ZeroTier、WireGuard、Docker、Wi-Fi Direct 等虚拟网卡；机器完全没有 IPv4 时才退回 IPv6（二维码里是带方括号的地址）。

macOS / Windows 打包：`./build-mac.sh <版本>`、`./build-windows.sh <版本>`，产物在 `dist/`（macOS 为 `.app` 与 zip，Windows 为 zip）。

## 数据存储

目录优先级：`-data` > 环境变量 `LANOCLIP_DIR` > 各平台默认用户配置目录下的 `LanCoClip/`：

| 平台 | 数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/LanCoClip/` |
| Windows | `%APPDATA%\LanCoClip\`（`C:\Users\<用户名>\AppData\Roaming\LanCoClip\`） |

目录内容：

| 文件 | 内容 |
| --- | --- |
| `texts.json` | 文本记录 |
| `images.json` | 图片记录元数据 |
| `images/` | 图片原图 PNG（文件名即记录 id） |
| `settings.json` | 保留条数、快捷键、暂停状态等配置 |
| `app.log` | 运行日志（托盘模式没有终端，排查问题看这里）；超过 2 MiB 轮转为 `app.log.1` |
| `instance.lock` | 跨进程单实例锁文件（OS 持有，进程退出自动释放） |
| `*.corrupt-<时间戳>` | 损坏 JSON 的留证备份（自动改名保留，最多留最近 3 份） |

- 备份 / 迁移：把整个目录拷走即可（`images/` 与两个 json 一起拷）。
- 可靠性：json 用「临时文件 + 重命名」原子写；两份记录先都准备好再依次替换；损坏的文件会改名留证并写日志，不会静默清空历史；启动时回收 `images/` 里没有记录引用的无主图片（元数据损坏时跳过回收，避免误删）。写盘失败会在页面顶部横幅提示，并在 `app.log` 留痕。

## 安全与隐私边界

服务默认监听所有网卡，同一局域网内的设备可以读取记录（无鉴权是产品的既定取舍，请只在可信网络使用）。页面也是明文 HTTP 下发，同网攻击者除了读接口，还能嗅探或篡改页面内容。在**不引入口令**的前提下，内置以下防护：

- **访问域名白名单**：所有请求（含只读接口）校验 `Host`，只放行 `127.0.0.1` / `localhost` / 本机网卡地址，挡住 DNS rebinding 把攻击者域名变成「同源」后读走全部历史。若通过代理或自定义域名访问，用环境变量 `LANOCLIP_ALLOWED_HOSTS`（逗号分隔，可写 `host` 或 `host:port`）追加。
- **跨站写请求拦截**：写接口校验 `Origin` / `Sec-Fetch-Site`，其它网站的页面不能偷偷清空历史、灌水或触发通知；非浏览器客户端（托盘、单实例探测、命令行）不受影响。
- **请求体上限**：所有写接口最多 32 MiB；`/api/add-text` 512 KiB、`/api/add-image` 32 MiB 另有更严限制；二维码 `text` 参数最多 1024 字节。
- **限流**：每个 IP 在 10 秒窗口内最多 60 次写请求、累计 96 MiB 上传，超限返回 429；无 `Content-Length` 的分块上传按上限预先计入窗口。图片上传串行执行，保证水位检查看到的是真实占用。
- **数据目录水位**：目录达到 1 GiB 后，推送接口返回 507，不再接收新内容；本机剪贴板捕获不受此限制。
- **单实例锁**：数据目录下的 `instance.lock` 由操作系统持有，避免两个进程同时启动写同一份数据、或第二个进程启动时误删第一个刚写入的图片。进程崩溃时锁自动释放，不留陈旧文件。
- **文件权限**：数据目录 0700、记录与日志文件 0600；启动时会把旧版本建的 0644 文件收敛过来。
- **安全响应头**：`nosniff`、`X-Frame-Options`、`Referrer-Policy`、限制同源的 CSP（页面含内联脚本/样式，故这两项保留 `unsafe-inline`）。
- **暂停记录**：可随时停止记录新的剪贴板内容。
- **本地明文**：`texts.json` / `images/` 是明文，复制过的密码、验证码、令牌都会留存；需要时请先暂停并清理历史。
- **残留清理**：启动时删除崩溃留下的 `*.tmp`，损坏备份 `*.corrupt-*` 只保留最近 3 份，避免它们永久占用 1 GiB 水位。

## 分发与签名

- macOS 与 Windows 共用 `build-config.sh` 里的版本号、应用名和构建时间，避免两个平台出包时不同步；也可用环境变量 `LANOCLIP_VERSION` 指定版本。
- macOS 包用本机生成的自签证书签名（证书与私钥在 `codesign/`，已 gitignore），并把证书加入 login 钥匙串的信任根，让辅助功能授权跨构建保持；**未做 Apple 公证**。拷到别的 Mac 会被 Gatekeeper 拦截，公开分发需要 Apple Developer ID 签名 + notarization。不需要该证书时可在「钥匙串访问」里删除。
- Windows exe 未做数字签名，SmartScreen 会拦截；「剪贴板监听 + 全局热键 + 开机自启」也是剪贴板类木马的常见特征组合，部分杀软可能误报。公开分发建议购买代码签名证书。
- p12 口令默认是 `lanoclip-sign`，可用 `LANOCLIP_SIGN_PASSWORD` 覆盖；改口令后需删掉 `codesign/lanoclip.p12` 让脚本重新生成。
